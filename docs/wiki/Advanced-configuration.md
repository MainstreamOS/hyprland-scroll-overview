Lua makes it possible to use ScrollOverview far beyond its default behavior. By combining the plugin's runtime configuration and dispatchers with Hyprland events, keybinds, and custom logic, you can build workflows tailored to the way you use your desktop or extend the plugin with entirely new interactions. The examples below are practical starting points that can be used as-is or adapted to your own configuration.

- [Dynamic workspaces](Dynamic-workspaces.md) — create a new workspace by scrolling past the last populated workspace
- [ALT + Tab overview](ALT-Tab-overview.md) — use ScrollOverview as a visual window switcher
- [Toggle scroll direction](Toggle-scroll-direction.md) — temporarily change the scrolling mode while holding Shift
